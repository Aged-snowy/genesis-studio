# Genesis Studio

Speak it, and it is built.

Genesis Studio turns pictures, photos, 3D models and schematics into blueprints for **Genesis**, a Minecraft Bedrock add on.
It works in any web browser on Windows, Mac, ChromeOS, Linux, Android, iPhone and iPad, and can be installed as an app.

Open it at **https://aged-snowy.github.io/genesis-studio/**

Genesis and Genesis Studio are made by PixelProphetOG.
